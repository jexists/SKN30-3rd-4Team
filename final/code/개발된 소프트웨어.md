# 개발된 소프트웨어: RAG 기반 LLM과 벡터 데이터베이스 연동 구현 코드

vs_method.py(벡터DB 연동 기반) → embed_chunks.py(임베딩 준비) → ingest_supabase.py(적재) → graph.py(LLM 오케스트레이션·검색 활용)

### vs_method.py
- 벡터DB 연동 핵심.
- Supabase(pgvector) 스키마 생성, OpenAI 임베딩(text-embedding-3-small), 문서 청킹·적재(ingest_document), 코사인 유사도 검색(search_similar)까지 RAG의 "검색" 절반을 전부 담당

### embed_chunks.py
- 청크 텍스트를 vs_method와 동일한 임베딩 모델로 배치 임베딩해 벡터DB 적재 전 단계 산출물을 만듦 (LLM↔벡터DB 연동의 "데이터 준비" 과정)

### ingest_supabase.py
- 임베딩 결과를 실제 Supabase kb_chunks 테이블에 INSERT — 벡터DB 연동의 "적재" 실행부

### graph.py
- LLM 연동 핵심.
- LangGraph로 의도분류→검색→답변생성 흐름을 구성. vs_method.search_similar() 결과를 근거로 ChatOpenAI가 답변을 생성하는 RAG 오케스트레이션 그 자체
